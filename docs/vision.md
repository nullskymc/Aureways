# 远期设想

这里记的是还没做的方向，不是当前行为，也没有排期。当前应用是：本机 ACP 客户端，原生窗口壳，界面在 WKWebView 里。

## 远端机器上的 Agent

编译、测试和仓库经常在另一台 Linux 或开发机上。设想是 Mac 仍只做界面，用 SSH 把 ACP 的 stdio 流转到那台机器上已经安装的 CLI。文件和终端调用发生在远端工作区。权限仍由本机页面决定。

现在每一次会话都是本机 `Process`。没有 SSH 传输，也没有远端 `cwd`。

## 离开电脑之后

一轮任务可能比人在座位上的时间长。设想两种离机方式，都还没做：

- 本机通过 Bot（例如 Telegram 或飞书）把待批准的命令推到手机，回复写回当前会话。不假设有公网服务器。
- 本机临时开一个只含进度和批准按钮的页面，手机扫码打开。它不是现在的菜单栏页；菜单栏只在这台 Mac 上显示额度和最近会话。

## 不做的事

这些设想不把 Aureways 变成托管模型的服务。Agent 仍然是用户自己的 CLI。额度、登录和密钥留在各家工具里。
