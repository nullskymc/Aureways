# 远期目标与愿景 (Vision & Roadmap)

本文档记录 Aureways 面向未来演进的远期能力设想。这里不涉及具体的排期节奏与实施细节，仅描绘功能场景与产品愿景，作为后续架构设计的长期指引。

---

## 愿景：从“本地会话窗口”到“全天候 Agentic 枢纽”

Aureways 的核心特色是**极简、轻量、纯原生**。未来的远期演进不会牺牲这一本质，而是利用 macOS 原生系统的管道能力与网络协议，将开发者从“必须坐在电脑前盯着代码跑完”的物理束缚中解脱出来，使 Aureways 成为一个随时待命的 **Agentic 中枢（Host Hub）**。

---

## 一、远端开发机 Agent 控制 (Remote Agent via SSH)

### 场景描绘
随着大模型编码任务与工程规模的扩展，重度编译、GPU 训练与生产级 Docker 往往运行在远程 Linux 服务器、云端开发机（DevBox）或局域网主机中。

Aureways 将支持**原生无缝调度远端机器上的 ACP Agent**（如远程服务器上的 Codex CLI、Claude Code 等）：
- **零额外依赖的管道穿透**：桌面端依然保持极简纯原生界面，仅通过标准 SSH 管道透传 ACP 的 JSON-RPC 协议流。
- **本地界面，云端算力**：用户在 Mac 上享受高帧率的原生渲染、Markdown 排版与主题质感，而底层的代码检索、文件变更及长任务测试完全在远程服务器上默默运行。
- **双向协同**：支持将远端工作区的改动与终端输出实时回传到本地工作台，亦可配置反向权限代理。

---

## 二、移动端伴侣与离机远程控制 (Mobile Remote Control)

### 场景描绘
Agent 执行复杂重构、跑全套测试或定位 Bug 时往往需要较长时间。开发者离开办公桌（吃饭、开会、通勤）时，工作流程不应被迫中断。

Aureways 将提供轻量化的离机控制能力，使手机或移动设备成为 Mac 客户端的“随身遥控器”：

### 1. 即时审批与消息 Bot (Telegram / 飞书 Bot)
- **免公网服务器的极轻量接入**：Mac 本地通过系统原生网络长轮询机制与 Bot 平台联动，用户无需配置复杂的公网 IP 或云服务。
- **掌上权限决策**：当远端或本地 Agent 触发危险命令（如 Shell 执行、批量删除）而暂停等待批准时，手机即时收到包含上下文的交互卡片，单击即可完成 `[允许]`、`[拒绝]` 或 `[中断]`。
- **随时追问与下达指令**：在手机聊天窗口中直接回复文字或语音指令，Mac 自动同步至活动会话并驱动 Agent 继续工作。

### 2. 扫码即用的轻量 PWA 移动控制台
- **无需应用商店审核与繁琐证书**：Mac 端一键生成动态配对二维码，手机扫码即可在 Safari 中打开全屏运行的 PWA 控制界面。
- **随身进度看板**：支持实时查看当前会话的思考链、工具调用卡片与流式输出，离开电脑也能对任务全局尽在掌握。

---

## 三、跨跳控制链拓扑 (Mobile → Mac → Remote Agent)

### 场景描绘
融合上述两种能力，形成端到端的闭环控制链：

$$\text{随身手机 (移动端 / Bot)} \xrightarrow{\quad\text{即时掌控 / 权限审批}\quad} \text{Mac Aureways (常驻中枢)} \xrightarrow{\quad\text{SSH 隧道透传}\quad} \text{远程开发机 (Codex CLI / ACP Agent)}$$

- **Mac 充当任务托管中心**：Mac 保持长连接与会话状态持久化，避免移动端网络抖动导致任务中断。
- **远程服务器承担繁重计算**：远端负责执行大规模代码生成与耗时验证。
- **手机充当极简总控台**：开发者无论身处何地，随时随地掌握万公里外服务器上的代码演进。

---

## 设计哲学守则

未来探索以上功能时，仍将严格坚守 Aureways 的立项原则：
1. **轻量与纯原生**：不引入臃肿框架与重型后台运行时，优先使用 macOS 与 Swift 系统内置的网络与进程能力。
2. **按需激活 (Opt-in)**：所有远程控制模块均为可选能力，未开启时保持 100% 纯本地单机运行，零额外资源占用。
3. **安全与掌控感**：所有远程操作默认保留明确的人工审批关卡，不牺牲安全性。
