# 前端

窗口里的界面在 `WebApp/`。技术栈是 Preact、`@preact/signals`、Vite。没有第二套 SwiftUI 对话视图。

## 布局

```
┌──────────────┬──────────────────────┬────────────────────────────────┐
│ 侧栏          │ 聊天                  │ 变更 · 终端 · 文件 · 打开文件  + │
│              ├──────────────────────┼───────────────────────┬────────┤
│ 新对话        │ 当前会话或欢迎页       │ 当前工作区标签内容      │ 文件树 │
│ 工作区与会话  │                      │ 文件 / diff / 终端     │        │
│ 文稿          │ 输入框固定在底部       │ 终端隐藏右侧文件树      │        │
└──────────────┴──────────────────────┴───────────────────────┴────────┘
```

侧栏宽度记在页面偏好里，拖完约 250 ms 后经 `uiPrefs` 交给原生保存。设置是另一条路由，Esc 回到对话。工作区里的文件或终端标签上按 Esc 回到对话标签。文稿上按 Esc 留在文稿。

顶栏高度让开红绿灯。页面把按钮标成不可拖，并把这些矩形交给原生拖拽条（`dragRegions`）。

## 对话列表

`VirtualList` 按行测量高度，只挂视口上下各一段（overscan 900px）。行是绝对定位。

钉在底部是默认状态。只有用户手势能离开底部：滚轮、指针按下、触摸、以及不在输入框里时的 Page Up/Down、Home/End、方向键、空格。测量一行会把 `scrollHeight` 撑高；若把这次滚动当成用户上滑，钉就会松开，最后几行会停在输入框底下。非手势的滚动若发现不在底部，会重新钉回去。

底部留白不是把内容盒的高度直接加成 `total`。内容盒高度是各行之和，后面跟一块流内的 `.vpad`，高度为 `padBottom`。对话页的 `padBottom` 是停靠区高度加 24。这样最大滚动位置是 `scrollHeight - clientHeight`，最后一行停在输入槽上方大约四十像素。

「回到底部」在离开底部后出现。浮层打开时，它的 `bottom` 还要加上弹出层超出卡片的那一截（`composerTotal - composerH`）。

## 正文

Agent 正文按顶层块切。流式时已经闭合的块不再重画，未闭合的块继续接。HTML 经过 DOMPurify。代码高亮用 Shiki（JavaScript 正则引擎），语法和主题按需加载。

工具行按 `toolCallId` 合并。思考可以折叠。ACP 的 `plan` 只活在它第一次出现的那一条消息里。这一轮还在生成、并且还有未完成步骤时，固定在流的最下方，不进正文，也不把工具流切开。全部完成后，或者这一轮已经结束（正常停、取消、出错、进程退出）但仍有未完成步骤时，放到这一条消息正文的正上方。后面的消息不再画同一份清单。步骤状态保持原样，未完成的不会被改成完成。这些展开状态留在页面里，不进 `AppModel`。

用户消息可以带附件。图片在 Agent 声明接受图片、并且 base64 不超过内联上限时，作为 `image` 内容块发出；否则降成 `resource_link`，由 Agent 自己读。超长粘贴不进输入框，写成工作区 `.aureways/pastes/` 下的草稿再作为文本发出。

## 输入框

`Composer.tsx` 同时给主页面和浮层用。Return 发送，Shift+Return 换行。生成中 Return 和停止按钮都是 `cancel`。`/` 与 `@` 的补全盖在卡片上，不参与文档流，避免把对话顶上去。

浮层模式见 [web-shell.md](web-shell.md)。槽的高度跟原生报来的卡片高度，弹出菜单变高时槽不变，只有回到底部的按钮上移。

## 主区域标签

聊天固定在最左栏，不能关闭或移走；变更、终端、文件和「打开文件」共享右侧工作区标签栏。默认左右宽度为 1 : 1.9，右侧初始显示「打开文件」，终端按需新建，不会自动启动 shell。最多三栏，每栏各有一条标签栏。除聊天外的标签均可关闭，并从 + 菜单重新打开。文件树属于右侧工作区内部，标签栏横跨内容与文件树；终端显示时隐藏文件树。同一工作区换会话时，文件和终端留在原地。

工作区以外打开的 Markdown 不进任何工作区，收在侧栏底部的「文稿」里。文稿钉在会话列表和设置之间，搜索会话时也还在。点开它不改当前工作区。文稿里只有文件标签，没有对话、变更、文件树、输入框和终端。在文稿里新建的笔记写到 `~/.aureways`。从别处打开的文件仍用原来的路径，不复制过去。这个目录不会成为工作区，Agent 也不会把它当作工作目录。

文稿里打开过的路径会记住，下次启动还在，但不会自动切到文稿。分栏不记，恢复时合成一栏。

| 标签 | 内容 |
| --- | --- |
| 对话 | 当前会话。输入框只在最左栏显示对话、并且当前不是文稿时，出现在那一栏底部 |
| 变更 | 工作区 `git.diff` 或本会话工具修改；右侧列表切换当前 diff，不额外打开标签 |
| 打开文件 | 文件选择空态和可筛选的工作区目录树 |
| 文件 | `fs.read`，`⌘S` 走 `fs.write`。mtime 不一致则拒绝覆盖 |
| 终端 | xterm.js。`term.open` 在原生侧起一条登录 shell；输出是 base64 的 `termData` |

点工作区的一栏，之后打开的文件进这一栏；从聊天区打开文件也会进入右侧，不替换聊天。工作区里的文内链接留在该工作区，文稿里的链接留在文稿。右键工作区标签选「移到右侧」，或按 `⌘\`，把它移到右边一栏。同一文件全局只有一个标签，换层时是挪过去。移走后这一栏选中相邻标签。标签栏支持方向键、Home / End 切换，关闭按钮和鼠标中键可关闭标签。拖动分隔线仅按像素比例重新分配相邻两栏的总 flex 权重，不改变第三栏权重。右边一栏的最后一个可关标签关掉后，这一栏消失。工作区里按 Esc 回到最左栏的对话，分栏还在。

终端实例和输出订阅按 `termId` 由标签持有，不依赖某一栏的组件生命周期。移栏、进入设置或切工作区时，视图可以卸载；返回时把同一个 xterm DOM 接回新容器，保留缓冲与滚动状态。关掉标签才释放实例并发 `term.close`；初始化未完成时关闭，也会回收晚到的实例。应用退出时 `AppDelegate` 关掉全部 PTY。

聊天标题栏右侧的面板按钮或 `⌥⌘I` 收起、展开**整个右侧标签区**，包括额外分栏；没有右侧标签时则打开「打开文件」。收起只隐藏栏，不卸载内容、不关闭标签：未保存编辑、滚动位置、选中标签、栏宽与运行中的终端均保留，聊天填满剩余宽度。展开恢复原来的分栏和焦点。折叠状态按工作区隔离，不影响文稿；打开或选中右侧文件、变更、终端时会自动展开。

右侧标签栏的文件夹按钮只切换内部文件树，与整个标签区的折叠相互独立。`⇧⌘E` 打开「打开文件」标签、展开文件树并聚焦搜索，宽度记在 `inspectorWidth`。还没进入会话也可以浏览文件；文稿仍不显示工作区文件树。点树里的文件在当前栏打开标签，树留在原地。

`⌘O` 和「用 Aureways 打开」的 `.md`：路径在当前工作区里，就在该工作区打开并回到主界面；在工作区以外，就收进文稿并切过去。打开文件不切换工作区。Markdown 用同一套渲染，并多做文档才需要的事：标题锚点、右侧大纲、相对路径的图片（读成 data URL）、指向其他 Markdown 的链接再开一个标签。窗口已经可见时，这次打开不重新拉起窗口，也不把它搬到文件所在的屏幕。SwiftUI 场景不接收这个外部打开事件，避免整页重载闪一下。

文稿的文件标题上没有 @。点「讨论」会在当前工作区新建对话，并把这个文件带进输入框。

## 设置与菜单栏

设置六页：通用、Agent、用量、工作区、权限、MCP。数据来自 `settings.refresh`，修改走 `settings.set` 或对应的 `agent.*` / `workspace.*` / `mcp.*` / `quota.refresh`。

菜单栏是同一个包的 `#menubar`。它不自己轮询额度；面板变为可见时发 `menuBarOpened`，由 `QuotaStore` 决定要不要真的请求。退出进程只在这里（`quitApp`）。`⌘Q` 只关主窗口。

## 通知

`AttentionNotifier` 在用户没看着那条会话时，为新的权限、计划、选择题发系统通知；应用在后台时，一轮结束也会通知。Dock 角标是待处理的条数。点通知会打开对应会话。

## 演示

`npm run dev` 或直接打开构建产物时没有 WebKit handler，`demo.ts` 提供假状态。查询参数 `?turns=N` 加长对话，`#settings` 和 `#menubar` 切页面。这不能代替在 WKWebView 里看玻璃和浮层。

标签页视觉回归：启动 Vite 后访问 `/tests/fixtures/workbench.html`，使用真实组件与模拟原生桥验证文件树、diff 和终端切换；`?dark` 检查深色模式。此页面不读取磁盘、不运行真实 shell，不包含在生产入口中。
